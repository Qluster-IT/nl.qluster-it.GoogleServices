Free usage & billing

These are Google's published allowances, not a balance or a spending limit. Your region, billing plan, and usage outside Homey can affect what you pay.

View allowances by service
Google TTS (without Cloud)
No API key or Google Cloud billing setup. The app allows up to 200 characters per message. This uses an unofficial endpoint with no guaranteed usage allowance.
Cloud Text-to-Speech
Billing is required. Google's monthly free allowance depends on the voice: 4 million characters for Standard or WaveNet, or 1 million characters for Neural2, Studio, or Chirp 3: HD. Do not assume every voice has a free tier. Text-to-Speech pricing
Cloud Translation
Billing is required. The default translation model includes the first 500,000 characters per month through a monthly credit. Usage above that is billed. Cloud Translation pricing
YouTube search
The YouTube Data API normally allows 100 search requests per project per day at no charge. The quota resets at midnight Pacific Time. If exhausted, searches can fail until it resets. YouTube quota details
Google Maps routes, images and address suggestions
Billing is required. Under global pay-as-you-go pricing, Google's free monthly caps are 10,000 Essentials route requests, 5,000 Pro route requests (including traffic-aware driving without traffic colors), a separate 10,000 Static Maps image requests, and 10,000 Places Autocomplete requests. Pairing and one-off Flow address suggestions use per-request autocomplete billing, not unlimited session pricing. Searches start at 3 characters; pairing waits until you pause typing for half a second. Use typed address lets you select a manual address or coordinates without Places API. The app does not poll automatically; each device or Flow refresh can incur usage. Google Maps pricing

Check your actual usage in Google Cloud Console. Lower API quotas where available to limit requests; billing budgets and alerts do not automatically stop charges.

Google Maps

Maps uses its own API key. It does not use the Translate project ID, Cloud service account JSON, or YouTube key.

Google Cloud requirements
  1. In Google Cloud Console, select the project that owns your Maps API key and make sure it is linked to an active billing account.
  2. Enable Routes API for travel time, distance, and estimated arrival. Enable Maps Static API only if you want route images. Enable Places API (New) for address suggestions during device pairing and in the one-off Flow card; it is optional if you enter full addresses or coordinates manually. If Google prompts you to accept the Maps Platform terms for your billing region, do so in the Console.
  3. Under APIs & Services → Credentials, use a dedicated Maps API key. Under API restrictions, allow Routes API, Maps Static API for images, and Places API (New) for pairing and Flow address suggestions. Under Application restrictions, do not use website (HTTP referrer) restrictions: Homey makes server-side requests. If you restrict by IP address, allow Homey's public outbound IP, not its local network address.

Keep your existing Maps key if it meets the requirements above.

On by default. Requires Maps Static API to be enabled and allowed for your Maps key. Disable this option if you do not want route images. After a device or Flow refresh, Homey requests the image only when it needs to display it, then reuses that image until the next refresh. There is no automatic polling or app-imposed refresh limit. Image requests can incur charges. If an image request fails, refresh the route to try again.

On by default. Applies to driving routes on the next refresh when route images and traffic colors are also enabled on the device. Green means normal traffic, orange means slow traffic, and red means a jam. Google bills these route calculations at the Routes Enterprise tier. Turning this off does not disable the estimated traffic delay reading.

Maps device setup

When pairing a Maps route device, choose an origin and destination using address suggestions or select Use typed address for a manual address or latitude, longitude. This option stays available if Google suggestions cannot be loaded. Select a travel mode and whether to show a route image and traffic colors. Use Repair on an existing device to edit these options with address suggestions, or use Advanced Settings to edit them manually. Selected Google locations are saved as place_id: followed by a place ID, which you can replace with an address or coordinates. Press Refresh route on the device or run the saved-route refresh Flow action. The app does not poll in the background.

To view an image, leave Enable route images here and Show route image on the device enabled (both are on by default). Refresh the saved route, then open the device's camera image.
