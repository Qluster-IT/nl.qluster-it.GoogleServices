Create a device per room and/or for the whole home.

Start a speech flow for that device and it will trigger a flow with an URL.
This works great with other Apps like Sonos and Samsung Smart TV (Laung Browser with the URL).

You can add a Google TTS "device" as many times as you would like, each with its own trigger.
You can set the output language per device.
When creating a device it will be configured based on your own language.

These languages are currently supported:
Engels (GB)
English (US)
Dutch (NL)
Dutch (BE)
German (DE)
German (LU)
French (FR)
French (BE)
Spanish (ES)
Italian (IT)
Swedish (SV)
Norwegian (NO)


If you would like a lnaguage to be added, create a pull request.
